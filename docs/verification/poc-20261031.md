## PoC の中で見つけ、修正した点
1. **受信済み・ACK 待ちのメッセージで、もう一度通知していた**（Claude で余分なターンが発生）。新着の判定を「一度も受信されていないもの」に限定して修正した。自動試験を追加し、10/10 合格。本番の設計（known_seq）では考慮済み。
2. **Codex が依頼に返信しなかった**（答えを自分の画面に書いただけ）。原因は、Codex では MCP の instructions がツールの説明としてしか渡らず、通知文（利用者の入力として届く）の「受信して ACK して」が優先されたこと。通知文に「依頼なら実行して poc_send で返信する」を加えたところ、返信するようになった。
